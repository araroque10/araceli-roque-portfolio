# Medical Image Generation with GANs

## Overview

This project contains Python code from a master's thesis focused on generative modeling for medical image structures using GAN-based training.

## Contents

- `src/train.py`: main training loop.
- `src/model.py`: generator and discriminator models.
- `src/bonedataset.py`: dataset loading logic.
- `src/structuralparameters.py`: structural parameter computation.
- `src/utils.py`: training utilities and helper functions.
- `reports/masters-thesis.pdf`: thesis document.

## Technologies

Python, PyTorch, GANs, medical image analysis, structural parameter evaluation.
